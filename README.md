# English School

Інтерактивні уроки англійської за підручником **Roadmap C1-C2** (Student's Book + Workbook) у вигляді статичних HTML-сторінок: без бекенду, без збірки, працює й з `file://`.

## Структура

- **Модулі** — набори юнітів книжки (`content/modules.js`): Module 1 = юніти 1–3, Module 2 = 4–6, Module 3 = 7–10.
- **Уроки** — як у книжці: 1A…10D (A–C — граматика й лексика, D — English in action). Кожен урок — файл `content/uNN/<id>.js`.
- **Режими уроку:**
  - **Learn** — вивчення за Student's Book: правило, лексика, вправи уроку, говоріння;
  - **Homework** — вправи Workbook;
  - **Refresh** — повторення всього разом (Language bank, Vocabulary bank, Check and reflect, Module test revision, додаткові вправи).
- На рівні модуля: змішаний тест, картки з інтервальним повторенням, робота над помилками.

Техніки: правило з прикладами й озвучкою, вибір відповіді, пропуски, збирання речень, перефразування з моделями, пошук помилок, флешкартки, пари, сортування, говоріння/письмо з підсвічуванням цільових фраз і диктуванням. Прогрес зберігається в `localStorage` (старий прогрес Module 1 переноситься автоматично).

## Запуск

Відкрий `index.html` у браузері або увімкни GitHub Pages для гілки.

## Debug-режим

Натисни 🐞 у верхній панелі (або додай `?debug` до адреси). Поки режим увімкнено, кліки не відповідають на вправи, а відкривають поле для коментаря до елемента, на який ти клікнув. Внизу є панель зі списком коментарів. Кнопка **⬇ Завантажити** зберігає їх у файл `debug-comments-YYYY-MM-DD.md`. Кожен коментар у файлі прив'язаний до уроку, режиму, вправи й пункту, тож цей файл можна покласти в тред і попросити Claude доопрацювати. Коментарі зберігаються в браузері, доки їх не очистиш.

## Розробка

- `app/` — рушій (`app.js`), чисті функції (`core.js`), debug-режим (`debug.js`), стилі.
- `content/` — уроки, модулі, карта сторінок книжки (`page-map.js`).
- `docs/content-guide.md` — як писати урок і формати вправ.
- `tools/extract_pages.py` — рендер сторінок зі сканів у `.cache/pages/` (PDF лежать у `sources/`, у git не потрапляють).

```bash
node tools/validate.js         # перевірка всіх уроків
node tools/sync-index.js       # оновити <script> уроків в index.html
node --test "tests/*.test.js"  # тести
```
