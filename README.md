# English School

Інтерактивні уроки англійської у вигляді статичних HTML-сторінок (без бекенду, без збірки).

## Module 1 · Revision

`module1/` — застосунок для повторення тем Module 1 (Language bank 1A–3C і Module test 1):

- **Граматика:** perfect forms, subject raising, infinitive phrases, continuous aspect, probability, cleft sentences, question forms, reason clauses, modifying adjectives.
- **Лексика:** activity collocations, emotion idioms, attitude adjectives, trends, reacting to proposals, ideas, thinking verbs.

Техніки навчання: правило з прикладами й озвучкою, вибір відповіді, заповнення пропусків, збирання речень, перефразування з моделями, пошук помилок, флешкартки з інтервальним повторенням, пари, сортування, говоріння/письмо з підсвічуванням цільових фраз і диктуванням, змішаний тест. Прогрес зберігається в `localStorage`.

### Запуск

Відкрий `module1/index.html` у браузері (працює й з `file://`) або увімкни GitHub Pages для гілки — корінь репозиторію перенаправляє на `module1/`.

Увесь контент лежить у `module1/data.js`; щоб додати вправу, додай об'єкт у масив `exercises` потрібної теми (формати описані на початку файлу).
